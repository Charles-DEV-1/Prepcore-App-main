 
 
1. Project Overview

Prepwise is a Nigerian JAMB and WAEC exam prep platform. This document is the complete specification for the mobile app version. The mobile app must match the web platform exactly in functionality, data, and brand identity.

3. Technical Architecture

3.1 Project Setup
Install Expo: npx create-expo-app prepwise --template blank-typescript
Install NativeWind: npm install nativewind tailwindcss — configure tailwind.config.js and babel.config.js
Install navigation: npm install expo-router — use file-based routing
Install Supabase: npm install @supabase/supabase-js @react-native-async-storage/async-storage — AsyncStorage replaces localStorage
Install other deps: npm install zustand @tanstack/react-query react-hook-form zod expo-notifications expo-secure-store
 
3.2 Supabase Connection
Use the SAME Supabase project as the web app. Same URL, same anon key, same database. All data is shared.
 
 
Supabase client setup (src/lib/supabase.ts):
import AsyncStorage from '@react-native-async-storage/async-storage'
import { createClient } from '@supabase/supabase-js'
export const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY, { auth: { storage: AsyncStorage, autoRefreshToken: true, persistSession: true, detectSessionInUrl: false } })
 
3.3 Authentication — Google OAuth
Setup: Use @react-native-google-signin/google-signin package. Configure with the same Google OAuth Client ID used on web.
Flow: User taps 'Continue with Google' → Google sign-in sheet appears → on success, get idToken → call supabase.auth.signInWithIdToken({ provider: 'google', token: idToken }) → session created → navigate to dashboard or onboarding.
Deep linking: Configure app scheme (prepwise://) in app.json for OAuth redirect. Add to Google Cloud Console authorized redirect URIs.
Session persistence: Supabase with AsyncStorage handles this automatically. Check session on app launch.
Middleware equivalent: Use a root layout file that checks auth state. If no session, redirect to login screen. If session but no onboarding, redirect to onboarding.

Logout: Call supabase.auth.signOut(), clear all AsyncStorage keys, navigate to login and reset navigation stack.
 

6. Premium System

The premium system works identically to the web. All plan checks are made against the Supabase subscriptions table.
 
6.1 useUserPlan Hook
Create the same hook as the web — check subscriptions table for the logged-in user. Returns isPro boolean.
Query: supabase.from('subscriptions').select('plan, status, current_period_end').eq('user_id', user.id).maybeSingle()
isPro = plan === 'pro' AND status === 'active' AND current_period_end > today
Cache result in Zustand or React Query to avoid repeated calls
Bulk Pro: Also check if user's lesson center has bulk_pro_active = true via user_referrals join. If yes, user is Pro.
 
6.2 Free vs Pro Limits
 
6.3 Premium Gate Component
Create a <PremiumGate> component that wraps any premium feature.
If user is Pro: render children normally.
If user is Free: render a lock screen overlay with blurred background, lock icon, feature name, and 'Upgrade to Pro' button.
Usage: Wrap the Flashcards tab content entirely. Wrap AI explanation button. Gate unlimited exam access.
 

7. Offline and Performance

Cache questions: After loading a practice session, cache the questions in AsyncStorage. If the user loses connection mid-session, they can continue.
Cache dashboard: Cache last dashboard data for 5 minutes. Show cached data immediately on load, refresh in background.
Offline indicator: Show a subtle banner when the device has no connection. Don't crash — show cached content.
Question images: Questions are text-only for now — no images to cache.
Supabase realtime: Do not use Supabase realtime subscriptions in the mobile app. Use polling or pull-to-refresh instead to save battery.
 

8. Push Notifications

Setup: Use expo-notifications. Request permission on first launch after onboarding.
Streak reminder: If user has not opened the app by 7pm, send: 'Don't break your streak! Open Prepwise and study for 5 minutes.'
Weekly quiz alert: Every Monday at 8am: 'This week's quiz is live! See if you can top the leaderboard.'
Score milestone: When a student's average score improves by 10+ points: 'Your average score just jumped to X%! Keep going.'
Implementation: Use Expo's push notification service for development. For production, send notifications via Supabase Edge Functions or a cron job.
Permission handling: If user denies permission, never ask again. Don't nag. Notifications are a bonus, not required.
